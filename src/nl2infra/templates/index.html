The Gauntlet Rule Catalog (Checkov + OPA + Dry-Run)

Role-gated security policies running locally inside every verification cycle.

BASE POLICIES (All Roles)
  • OPA_NO_ROOT: Containers must enforce runAsNonRoot: true
  • OPA_NO_PRIVILEGED: Prohibit privileged: true pods
  • OPA_NO_PLAINTEXT_SECRET: Block plaintext tokens/passwords in env
  • OPA_REQUIRE_CPU_LIMIT: Containers must define CPU limits
  • OPA_REQUIRE_MEM_LIMIT: Containers must define memory limits
  • PLAN_CONFORMANCE: AI cannot drop approved plan resources
STAGING POLICIES (senior_dev+)
  • OPA_REQUIRE_READINESS_PROBE: Pods must include readinessProbe
  • OPA_DISALLOW_LATEST_TAG: Image tags must be pinned (no :latest)
  • CKV_K8S_21: Namespace must have ResourceQuota configured
  • CKV_K8S_28: Ensure securityContext drop capabilities [ALL]
PRODUCTION POLICIES (platform_admin)
  • OPA_PRODUCTION_REPLICAS: Production Deployments must have >= 2 replicas
  • OPA_NO_DEFAULT_NAMESPACE: Strict ban on default namespace
  • OPA_READONLY_ROOTFS: Enforce readOnlyRootFilesystem: true
