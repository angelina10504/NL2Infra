About this pipeline
Gauntlet
Four independent checks inspect each generated draft and send violations back for a fix.
Checkov
Checkov scans infrastructure files for known cloud and Kubernetes security risks.
OPA/Conftest
OPA/Conftest applies the project’s policy rules to the generated files.
dry-run
A Kubernetes API dry-run checks whether the cluster would accept the proposed resources.
plan conformance
Plan conformance checks that generated resources match the plan you approved.
