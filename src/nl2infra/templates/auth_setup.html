Set up GitHub sign-in

The server is running. GitHub sign-in needs its OAuth app credentials before your team can use it.

  1. Open GitHub → New OAuth App. Enter these values:

    Application name: NL2Infra

    Homepage URL: {{ORIGIN}}

    Authorization callback URL: {{CALLBACK}}

  2. Copy its Client ID, generate a client secret, and enter them in your project's root .env file. Keep the secret private.
  3. Find your numeric GitHub ID at https://api.github.com/users/YOUR_USERNAME, in the id field. Set it as the initial admin ID: 
    GITHUB_OAUTH_CLIENT_ID=your_client_id
GITHUB_OAUTH_CLIENT_SECRET=your_client_secret
NL2INFRA_BOOTSTRAP_ADMIN_IDS=your_numeric_github_id
  4. Restart the FastAPI server after saving .env, then sign in.

The homepage and callback must be reachable at the configured address. A tunnel restricted to Slack interactions will need a separate sign-in address or deployment configuration.
